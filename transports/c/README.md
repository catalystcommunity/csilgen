# csilgen C transport library

A hand-written, dependency-free **C11** reference implementation of the CSIL
transport family (RPC, Events, Datagrams) over a hand-rolled canonical-CBOR
codec. It is the matched client + server peer of the Go, Python, Rust, and
TypeScript transport libraries, and is verified byte-for-byte against the shared
conformance vectors in `transports/conformance/`.

- **No async, ever.** Every call is synchronous and blocking; the host owns the
  I/O loop and threads (one blocking `csil_rpc_server_serve_one` per worker
  thread is the idiomatic concurrency story). One client/server object per
  thread; objects are not internally synchronized.
- **Zero external dependencies.** The canonical CBOR codec is hand-rolled (stdlib
  only), mirroring the other reference libraries.
- **Bring-your-own carrier.** The byte/datagram transport is injected as a vtable
  of function pointers plus an opaque `userdata`; built-in length-prefix stream
  and in-memory loopback carriers are provided for tests and simple hosts.

## Required toolchain

Only a C11 compiler (`cc`) and **CMake >= 3.18** are needed — no system packages.
(Validated locally with gcc 16.1.1 and cmake 4.3.3.) `clang-format` is optional:
the sources are already formatted to `.clang-format`, so it is never a build
dependency.

## Layout

```
include/csil/            public API (the only headers consumers see)
  csil.h                 umbrella convenience header
  csil_conventions.h     error codes, version, status registry, ownership helpers
  csil_carrier.h         BYO-carrier seam + built-in stream / loopback carriers
  csil_rpc.h             request / response / push + client + server
  csil_events.h          verbose + compact events + control-plane payloads
  csil_datagrams.h       cbor-array + compact-header datagrams + sequence tracker
src/                     implementation + internal-only headers (not installed)
tests/                   conformance + roundtrip tests (+ generated vectors.gen.h)
tools/gen_vectors.py     regenerates tests/vectors.gen.h from the conformance JSON
```

The canonical-CBOR codec lives entirely in `src/` (internal, like the
package-private `cbor.go` in the Go reference): hosts encode payloads with
generated code, not the transport, so the codec is not part of the public API.

## Building and testing

CMake is multi-step (configure + build + test), so a convenience script wraps it
and is what the repo's xtask runner calls:

```sh
./run-tests.sh        # configures, builds, and runs ctest under ASan/UBSan; non-zero on failure
```

Or by hand:

```sh
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build
ctest --test-dir build --output-on-failure
```

The conformance test reconstructs every vector in
`transports/conformance/{rpc,events,datagrams}.json` from its language-neutral
`input`, asserts `encode -> hex`, and asserts `decode(hex) -> the same envelope`.

### Regenerating the vectors header

`tests/vectors.gen.h` is checked in (so the build needs no Python), generated by:

```sh
python3 tools/gen_vectors.py ../conformance tests/vectors.gen.h
```

Run it only when the conformance vectors change.

## Consuming this library from git

C has no standard package manager, so "consumable from git" means **CMake +
git**. Three documented paths, in order of preference:

### (a) Git submodule + `add_subdirectory` (primary, fully offline)

```sh
git submodule add https://github.com/catalystcommunity/csilgen.git external/csilgen
```
```cmake
add_subdirectory(external/csilgen/transports/c)
target_link_libraries(myapp PRIVATE csil::transport)
```

### (b) CMake `FetchContent` (no manual submodule; network at configure time)

```cmake
include(FetchContent)
FetchContent_Declare(csilgen
    GIT_REPOSITORY https://github.com/catalystcommunity/csilgen.git
    GIT_TAG        <commit-or-tag>
    SOURCE_SUBDIR  transports/c)   # CMake >= 3.18 honors SOURCE_SUBDIR
FetchContent_MakeAvailable(csilgen)
target_link_libraries(myapp PRIVATE csil::transport)
```

`SOURCE_SUBDIR` is what lets the transport live in a subdirectory of the monorepo
without a wrapper repo — the C analog of Go's `module/transports/go` import. The
library guards its tests behind `PROJECT_IS_TOP_LEVEL`, so a consuming build never
compiles them.

### (c) Single-header amalgamation (zero build system)

For embedded / Make / Bazel users with no CMake, the sources can be concatenated
into a single translation unit and compiled directly (the stb/sokol convention).
The few `src/` files plus the `include/csil/` headers compile cleanly together.

## Ownership model (read once, applies everywhere)

- `const T *` parameter = **borrowed**; the library does not retain it past the
  call.
- `uint8_t **out` from an `*_encode` or a carrier `recv` = **transferred to the
  caller**; free it with `csil_free`.
- A value returned by a `*_decode` owns a single backing **arena**: every pointer
  inside it is valid until the matching `*_free`, which frees that arena once.
  (`csil_compact_datagram` uses a single heap copy instead of an arena; same
  one-free contract.)
- Every `*_new` has exactly one `*_free`; `*_free(NULL)` is a no-op.
- Optional integer fields pair a value with a `has_*` flag (C has no `Option<T>`);
  optional text fields use `NULL` to mean absent.
